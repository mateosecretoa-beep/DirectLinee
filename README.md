# 💬 DirectLine
### Tu gente, más cerca.

DirectLine es una plataforma de comunicación digital diseñada para conectar amigos desde cualquier lugar y dispositivo.

Su objetivo es ofrecer un espacio de conversación privado, rápido, moderno y fácil de utilizar.

## ✨ Características principales

- 💬 Mensajería instantánea en tiempo real.
- 👥 Sistema para agregar amigos.
- 🔑 Claves individuales para identificar y autorizar dispositivos.
- 🔒 Conversaciones privadas.
- 💾 Historial de mensajes.
- 🟢 Indicador de conexión.
- 📱 Diseño adaptable a móviles, tablets y computadoras.
- ⚙️ Panel de administración.
- 🗄️ Almacenamiento de usuarios y conversaciones.

## 🛠️ Tecnologías

- Python: lógica principal del servidor.
- Flask: aplicación web.
- Flask-SocketIO: comunicación en tiempo real.
- HTML5: estructura de la interfaz.
- CSS3: diseño visual.
- JavaScript: interactividad.
- SQLite / PostgreSQL: almacenamiento de información.

## 📋 Requisitos

Para ejecutar el proyecto necesitas:

- Una computadora con Windows, Linux o macOS.
- Python instalado.
- pip para instalar dependencias.
- Conexión a internet para instalar paquetes.
- Un navegador moderno.

Para publicarlo y permitir conexiones desde cualquier lugar también necesitas un servicio de alojamiento compatible con WebSockets y una base de datos persistente.

## 🚀 Objetivo del proyecto

Construir una plataforma de mensajería funcional, segura, escalable y accesible desde diferentes dispositivos.

## 📌 Estado del proyecto

En desarrollo. Las funciones y la infraestructura se irán probando y mejorando progresivamente.
